## コースの内容

| 項目 | 内容 |
|---|---|
| 専攻 | 文系：社会学、経営学、メディア学、表象文化論、教育学、日本語教育など／理系：情報学、生物学など |
| 講師 | 専攻ごとに、同じ分野を修めた講師が担当します。常勤講師が中心で、平均指導歴は4年以上です。 |
| 体制 | 主任講師（専門科目・研究計画書）、担任（進度と出願スケジュール）、アシスタント（質問対応・課題）の3人体制 |
| 授業 | 専門科目、ゼミ形式の授業（2020年から、研究室での議論の形を受験準備の段階に取り入れています）、研究計画書、面接練習、語学 |
| 日程 | 大学院の春・秋の入試に合わせて進めます |
| 体験授業 | 志望専攻の講師による通常授業に加え、1対1の学術面談を1回行います |
| 協力教授 | 元早稲田大学教授 森康晃 先生（面接練習・研究計画書の指導）、東京大学 理学博士 木山 先生（理系） |

## 実績

知日塾の集計（不完全統計）：2013〜2026年、文理大学院の合格は延べ **1,787名**（文系1,254名・理系533名）。文系では社会学705名、経営学239名、メディア学123名、表象文化論107名。2026年度の夏・秋入試では、文理大学院で223件の合格を得ました。

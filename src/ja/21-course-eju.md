## コースの内容

EJU の全科目に対応します：日本語（読解・聴解・聴読解・記述）、総合科目、数学（コース1・コース2）、物理、化学、生物。常勤講師が中心で、「教える・学ぶ・練習する・テストする・評価する」の流れで学習を進めます。

| 項目 | 内容 |
|---|---|
| クラス | 少人数クラス・個別指導。対面とオンラインを同時に実施 |
| 模擬試験 | 定期的に実施し、結果に応じて科目ごとの学習時間を調整します |
| 面談 | 毎月1回の個別面談で、担任が志望校と出願計画を見直します |
| 個別試験対策 | EJU の後に行われる筆記・小論文・面接・英語の対策を、志望大学の志望学部ごとに行います |
| 日本語（JLPT） | ゼロから N1 まで。年間を通じて随時開講します |
| 教室 | 東京・大阪・京都、成都・上海・杭州・広州・西安・武漢 |

## EJU の科目

| 科目 | 満点 | 主に必要な人 |
|---|---|---|
| 日本語（読解・聴解・聴読解） | 400 | ほぼすべての大学 |
| 日本語（記述） | 50 | 多くの大学 |
| 総合科目 | 200 | 文系 |
| 数学 コース1／コース2 | 200 | 文系は主にコース1、理系はコース2 |
| 理科（物理・化学・生物から2科目） | 200 | 理系 |

EJU は毎年6月と11月の年2回実施され、中国国内にも会場があります。
